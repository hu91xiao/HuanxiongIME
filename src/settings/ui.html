输入

决定按什么键、出什么候选。

方案
输入方式
五笔拼音混输：五笔打出来的字优先，拼音补全在后
五笔优先强度
只对混输有效。调太大时打短拼音会先出五笔码的字
分次选词先不上屏
选完一段继续选下一段，不立刻把整句打到屏幕上（fluid_editor）
回车直接上码
有候选时按回车，把输入的字母串直接上屏，中文用空格/数字选
记住选过的词
拼音方案启用用户词典，常用词自动靠前
候选栏
每页候选数
数字键 1~N 直接选词
候选后显示英文
每个候选后面跟一个英文释义（自己维护的词表）
Ctrl + 数字 上屏英文
不选中文，只把该候选的英文打出去
英文上屏风格
只影响 Ctrl+数字 打出来的写法，候选栏注释不变
配色
主题
晴蓝：冷白底；素白：极简黑白；夜墨：深色；云青：米底墨绿
排版
字号
候选文字大小，注释自动比它小 3 号
16 pt
排列方向
横排占屏宽，竖排占屏高
圆角
窗口四角弧度
14
候选间距
相邻候选项之间的空隙
20
翻页与选词
翻页键
上一页 / 下一页。Tab 与 Shift+Tab 始终可用
分号 / 引号 选第 2、3 个候选
开了以后 ; 等于数字 2，' 等于数字 3
中英切换
Shift 键
上码并切中英 = 按一下把编码打出去且切换状态（原版行为）
CapsLock 键
上码并切中英 = 大写锁定兼当切换键
方案菜单 Ctrl + 0　· 方案切换 Ctrl + `　· 清空输入 Esc　· Ctrl+数字 上屏英文（需在「候选」里开启）
常用动作
编辑自定义短语
custom_phrase.txt：一行一条，短语　编码　权重，制表符分隔
打开 Rime 用户目录
所有配置与词库都在这里
编辑 rime.lua
英文词表、回车上码、Ctrl+数字上屏都在这个脚本里
重新部署
手工改过 yaml 之后点这个；设置面板应用时会自动部署
配置备份
每次「应用并部署」都会自动备份，保留最近 10 份
换电脑 / 迁移
导出配置包
把方案、词库、rime.lua、英文词表和所有补丁打成一个 zip，默认存到桌面
导入配置包
在别的电脑上选这个 zip，自动备份、覆盖、部署并重启服务
幻熊输入法 1.0
虚幻引擎 / 游戏开发向的五笔拼音混输方案。深度优化游戏制作方面的词汇与英文， 内核基于开源项目 Rime 小狼毫 0.17.4（GPLv3）改造。
不联网、不上传、不收集任何输入内容。
