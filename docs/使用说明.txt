幻熊输入法 1.0 —— 使用说明
========================================

一、装好之后怎么打字
----------------------------------------
1. 按 Win + 空格（旧系统是 Ctrl + 空格），切到「幻熊输入法」。
   任务栏右下角出现小熊托盘图标就说明服务起来了。
2. 想用它当默认输入法：设置 → 时间和语言 → 语言 → 中文 → 选项，
   把「幻熊输入法」往上调。

二、它和普通拼音输入法有什么不一样
----------------------------------------
· 五笔优先、拼音兜底：会打五笔就打五笔（前四个码），不会就打拼音，
  两种混着打也行，五笔的候选排在前面。
· 英文直接回车：打一串英文，按回车立刻上屏，不用切输入法。
· Ctrl + 数字：把当前输入的原始编码直接上屏（比如打 raw 想保留原样）。
· - / = 翻页，分号、引号也可以选词。
· 候选后面带英文注释：打 wg 会告诉你 Widget 是什么。
· 词库里塞了 500+ 条虚幻引擎/游戏开发词汇（Blueprint、Niagara、
  MetaHuman、Lumen、Nanite、Dataflow……），中英混排都认。
· Shift 不会再误切中英文；大写锁定还是老规矩。

三、改设置
----------------------------------------
桌面（或开始菜单）的「幻熊输入法设置」——
· 输入：五笔/拼音/混输、英文注释、回车直上、Ctrl+数字
· 候选：每页 3/5/7/9/10 个、竖排横排、字重字号
· 外观：四套配色（晴蓝 / 素白 / 夜墨 / 云青）、圆角、间距
· 快捷键：翻页键、选词键、Caps Lock 行为
· 短语与维护：改自定义短语、导出/导入配置

改完点右下角「应用并部署」，等一两秒生效，打个字就能看到。

四、自定义短语
----------------------------------------
设置面板 → 短语与维护 → 「打开短语文件」，
一行一条：  上屏内容<Tab>编码<Tab>权重
例如：  Unreal Engine 5<Tab>ue5<Tab>100
存盘后点「应用并部署」。

五、常见问题
----------------------------------------
Q：切不到输入法 / 语言栏里没有它？
A：注销一次或重启，Windows 才会刷新输入法列表。

Q：候选框位置怪怪的？
A：虚幻编辑器这类自绘界面上，候选框可能不完全贴住光标，
   这是系统接口的限制，不影响输入。

Q：想彻底卸载？
A：设置 → 应用 → 幻熊输入法 → 卸载。
   你自己的词频、短语和配置（%APPDATA%\Rime）会保留，重装还能接着用。
